# Porsche Sales Intelligence Dashboard

Dashboard executivo desenvolvido para análise de vendas de veículos Porsche, com foco em **Business Intelligence, visualização de dados e geração de insights para tomada de decisão**.

O projeto transforma uma base de vendas em uma visão analítica organizada, permitindo identificar quais modelos possuem maior volume de vendas, como a demanda se distribui entre as cidades e quais formas de pagamento apresentam maior participação.

## 🎯 Objetivo do projeto

Criar uma visão executiva das vendas Porsche a partir de dados estruturados, utilizando indicadores e visualizações para responder perguntas de negócio de forma clara e objetiva.

O dashboard foi desenvolvido com uma abordagem voltada para portfólio de **BI**, priorizando:

- Clareza na apresentação dos dados;
- Indicadores relevantes para o negócio;
- Filtros interativos;
- Identificação de padrões de vendas;
- Comparação entre modelos e cidades;
- Geração de insights acionáveis.

## 📊 Perguntas de negócio

O dashboard foi estruturado para responder principalmente:

1. **Quais são os principais modelos de Porsche vendidos por cidade?**
2. **Qual combinação de modelo do ano e o  modelo que apresenta maior volume de vendas no período selecionado?**
3. **Quais são os modelos mais populares de acordo com os dados analisados em cada cidade?**

## 📌 Principais indicadores

O dashboard apresenta quatro KPIs principais:

- **Vendas:** quantidade de veículos vendidos no recorte selecionado;
- **Receita:** valor total das vendas;
- **Ticket médio:** valor médio por venda;
- **Modelo líder:** modelo com maior volume de vendas no filtro aplicado.

## 🔎 Filtros disponíveis

O usuário pode explorar os dados utilizando:

- Modelo da Porsche;
- Model Year;
- Cidade;
- Forma de pagamento;
- Período da venda.

Os gráficos e indicadores são atualizados de acordo com os filtros selecionados.

## 📈 Visualizações

O dashboard contém:

- Ranking dos principais modelos vendidos;
- Distribuição das vendas por Model Year;
- Cidades com maior volume de vendas;
- Participação por forma de pagamento;
- Tabela de modelo dominante por cidade;
- Cards de insights executivos.

## 💡 Insights de negócio

A estrutura do dashboard foi pensada para ir além da simples visualização dos dados. Os indicadores permitem analisar:

- **Preferências regionais:** identificação dos modelos com maior presença em cada cidade;
- **Mix de produtos:** compreensão de quais modelos concentram o volume de vendas;
- **Perfil temporal dos veículos:** análise da distribuição das vendas por Model Year;
- **Comportamento financeiro:** comparação das formas de pagamento utilizadas;
- **Concentração de receita:** identificação das cidades e modelos com maior impacto financeiro.
